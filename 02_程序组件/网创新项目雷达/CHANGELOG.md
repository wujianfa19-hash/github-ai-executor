# Changelog

## V1.3.0

- 从“规则/架构文档”升级为可执行 Node.js 程序。
- 新增 GitHub + Hacker News 低成本线索采集器。
- 新增可选 Brave Search 增强源，缺失 API Key 时不阻塞运行。
- 新增标准化、唯一 project_id、去重、快速评分和 Top-N 深度核验。
- 新增官网/README/社区讨论公开证据抓取，单源失败隔离。
- 新增 DeepSeek 严格 JSON 事实分析；模型失败时使用保守回退，不伪造事实。
- 新增程序侧证据完整度、大陆可执行性、真实到账置信度、行动指数和硬性降级。
- 新增 `data/state.json` 项目生命周期数据库（最多保留 500 个项目）。
- 新增关键条件变化检测：KYC、注册、提现、到账案例和行动指数变化。
- 新增每日邮件 + 变化提醒双通知模式。
- 新增无第三方 npm 依赖的单元测试。
- 新增 GitHub Actions 工作流，每天约 08:30 北京时间运行。
